# Data Model

Not applicable to CatWorld application data. This feature introduces no domain
entities, persistence model, API payloads, schema changes, browser storage,
external contracts, or structured product data.

The feature does define sidecar workflow artifact state for dependency layers,
child launch statuses, prepared child handoffs, and child-agent capability
checks. Those states are repository workflow contract data recorded in sidecar
artifacts, not CatWorld runtime data.
